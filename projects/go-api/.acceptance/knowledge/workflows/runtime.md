# Go API 本地运行环境

项目模块位于仓库的 `projects/go-api`，依赖清单为 `go.mod`，要求 Go 1.23+。从该目录执行 `go build -o <隔离输出目录>/stock .`，运行时传入 `--port <本机空闲端口> --state-dir <绝对状态目录>`。当前模块没有外部依赖；构建可关闭模块代理与自动工具链下载，并将 Go 编译缓存、模块缓存和临时目录放入本次验收的隔离运行目录。

运行环境 smoke 用临时状态目录及本机空闲端口启动二进制，对专用未知路径发出 HTTP 请求，只验证传输和进程可用，不判断业务状态码或响应内容。无论成功或失败都停止进程并清理临时目录。正式用例另建独立状态目录和端口。

新机器先核对 Go 版本、操作系统和架构，再以本机工具链的绝对路径在本次验收目录重新构建和 smoke；不可复制旧验收的二进制、缓存或通过凭据。此步骤来源于 AT-20261020-v1-go 的首次运行环境准备，在 be95265 上完成构建及 smoke。范围变更后须为新范围重新绑定并验证。
