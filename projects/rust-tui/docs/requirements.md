# 终端清单

这是一个在真实、支持颜色的终端中使用的本地交互程序，不依赖后台服务。验收环境使用 `TERM=xterm-256color` 且不设置 `NO_COLOR`；运行入口和状态文件格式见 README。

- TUI-01：使用 `--state <绝对路径>` 打开已有的 UTF-8 状态文件；缺少参数、文件不存在或格式错误时，退出码为 2，标准错误给出说明，不进入交互画面。每行格式为 `id|title|done`，id 是唯一的非空 ASCII 字母数字串，title 为 1 至 40 个可打印 ASCII 字符，done 为 `0` 或 `1`；文件至少有一项。
- TUI-02：在至少 80 列、24 行的真实终端，显示标题、全部可见项目的名称与完成状态、当前选中项及操作提示。文字应可读，选中项的文字与背景不能同色；标题、列表、提示和状态行不得互相遮挡。项目多于可见行数时仍能通过上下移动找到每一项。
- TUI-03：`j`/下箭头选择下一项，`k`/上箭头选择上一项；到达首尾时保持在边界。当前选中项有明确可见的标识；切换选择不修改文件。
- TUI-04：按空格切换当前选中项的完成状态，画面立即反映结果，状态文件也保存结果。再次按空格可恢复原状态；其他项不受影响。
- TUI-05：按 `q` 正常退出、恢复终端状态，退出码 0。若未切换状态，原文件字节不变；程序不在状态文件目录留下临时文件。
- TUI-06：终端小于 40 列或 10 行时应显示可读的尺寸不足提示，仍能按 `q` 退出，不发生布局遮挡或程序崩溃。终端重新放大后恢复正常列表。
